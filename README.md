# Lecture 03.2: Functions, Conditionals, and Scope

Short Python snippets for an introductory programming lecture. Each file is a small, runnable example to illustrate a single idea.

## Files
- [clamp.py](clamp.py): Implements `clamp` and prints sample calls.
- [asserts.py](asserts.py): Same `clamp` function, but uses `assert` statements as lightweight tests.
- [if.py](if.py): Minimal `if/else` syntax demo.
- [messy_event.py](messy_event.py): Intentionally unrefactored event cost estimator; mixes I/O with logic to motivate extracting functions.
- [pizza.py](pizza.py): Shows composition of helper functions (`area_circle`, `cost_of_pizza`) and formatted output.
- [scope_demo.py](scope_demo.py): Demonstrates variable shadowing and parameter passing.
- [LICENSE](LICENSE): MIT license for the repository content.

## Running the examples
Requires Python 3.9.11+.

Use these as starting points for exercises such as adding more tests to [asserts.py](asserts.py), refactoring [messy_event.py](messy_event.py) into functions, or experimenting with scopes in [scope_demo.py](scope_demo.py).
